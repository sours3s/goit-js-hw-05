# goit-js-hw-05

Домашнє завдання: чотири незалежні задачі на перебираючі методи масивів — `map`, `filter`, `toSorted` і ланцюжки методів.

## Завдання

- **task-1.js** — `getUserNames(users)` повертає масив імен користувачів.
- **task-2.js** — `getUsersWithFriend(users, friendName)` повертає користувачів, у яких є вказаний друг.
- **task-3.js** — `sortByDescendingFriendCount(users)` сортує користувачів за спаданням кількості друзів.
- **task-4.js** — `getTotalBalanceByGender(users, gender)` рахує загальний баланс користувачів певної статі.

## Перевірка

Відкрий `index.html` і подивись результати виклику функцій у консолі браузера.
